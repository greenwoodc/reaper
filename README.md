# Rock 2000 → Navidrome Pipeline

Scans your music collection, downloads missing tracks via Soulseek (Docker),
and creates **The Rock 2000 (2025)** playlist in Navidrome.

---

## Directory layout

```
rock2000/
├── config/
│   ├── sldl.conf              ← Soulseek credentials & download settings
│   ├── missing_tracks.csv     ← auto-generated by Phase 1, cleaned by Phase 1b
│   ├── download_log.txt       ← auto-generated by Phase 2
│   └── not_found.txt          ← tracks Soulseek couldn't source
├── slsk-batchdl-repo/         ← auto-cloned by Phase 2 (one-time)
├── docker-compose.yml
├── 01_scan_navidrome.py
├── 01b_cleanup_missing_csv.py ← Cleans search phrases (auto-run by Phase 2)
├── 02_download_missing.sh
├── 03_rescan_and_merge.py
├── 04_create_playlist.py
├── found_tracks.json          ← auto-generated by Phase 1
├── verify_clean_session.sh    ← Verify Soulseek session is clean
└── The_Rock_2000__2025_.csv   ← your Exportify export
```

---

## Pipeline overview

```
The_Rock_2000__2025_.csv
        │
        ▼
01_scan_navidrome.py
  Searches Navidrome (Subsonic API) for all 2000 tracks
  → found_tracks.json          (tracks already in /opt/4TBExt/Media/Music)
  → config/missing_tracks.csv  (tracks to download)
        │
        ▼
01b_cleanup_missing_csv.py [auto-run by 02_download_missing.sh]
  Removes remaster/edition suffixes and normalizes artist names
  (e.g. "War Pigs - 2009 Remaster" → "War Pigs")
  (e.g. "Motörhead" → "Motorhead")
  Improves Soulseek search hit rate significantly
        │
        ▼
02_download_missing.sh
  Builds slsk-batchdl Docker image (once), starts container,
  feeds cleaned config/missing_tracks.csv to sldl
  → downloads to /opt/4TBExt/Media/incoming/
        │
        ▼
03_rescan_and_merge.py
  Triggers Navidrome library rescan, waits for completion,
  re-searches for newly downloaded tracks, merges into found_tracks.json
        │
        ▼
04_create_playlist.py
  Creates (or updates) "The Rock 2000 (2025)" in Navidrome
  in countdown order — #2000 → #1, War Pigs plays last
```

## One-time setup

### 1 — Configure credentials

**`config/sldl.conf`** — set your Soulseek username and password:
```
username = your_soulseek_username
password = your_soulseek_password
```

**Each `.py` script** — edit the `CONFIG` block at the top:
```python
NAVIDROME_URL = "http://http://100.92.200.19:4533/"   # or your server's IP
ND_USER       = "admin"
ND_PASSWORD   = "xGdADq3Vt9uUFX"
```

### 2 — Fix PUID/PGID

The Docker container writes files as a specific user. It needs to match the
owner of `/opt/4TBExt/Media/Music` to avoid permission errors.

```bash
stat -c '%u:%g' /opt/4TBExt/Media/Music
# e.g. output: 1000:1000
```

If the result isn't `1000:1000`, edit `docker-compose.yml`:
```yaml
environment:
  - PUID=<your uid>
  - PGID=<your gid>
```

### 3 — Make scripts executable

```bash
chmod +x 02_download_missing.sh
```

## Running the pipeline

### Phase 1 — Scan your collection

```bash
python3 01_scan_navidrome.py
```

Takes a few minutes (2000 API searches with short delays).
Produces `found_tracks.json` and `config/missing_tracks.csv`.

Example output:
```
Loaded 2000 tracks. Scanning Navidrome...
  [2000/2000] Black Sabbath                — War Pigs

──────────────────────────────────────────────────────────────
  Found in collection :  843
  Missing             : 1157
──────────────────────────────────────────────────────────────
```

### Phase 2 — Download missing tracks

```bash
./02_download_missing.sh
```

This script automatically:
1. Cleans up search phrases in the CSV (removes remaster info, normalizes special characters)
2. Builds the slsk-batchdl Docker image (one-time only)
3. Downloads missing tracks via Soulseek

First run only: clones the slsk-batchdl repo and builds the Docker image
(takes ~2 minutes). The script pins slsk-batchdl to v2.6.0 because that
release targets net6.0 and builds cleanly with the bundled Docker SDK.
Subsequent runs skip straight to cleaning and downloading.

The container mounts:
- `./config` → `/config` (sldl.conf, missing_tracks.csv)
- `/opt/4TBExt/Media` → `/data` (download destination)

Downloads land in `/opt/4TBExt/Media/incoming/` organised as:
```
incoming/
└── Metallica/
    └── Metallica/
        └── Metallica - Enter Sandman.flac
```

Sldl prefers FLAC, accepts high-bitrate MP3 as fallback. It skips files
already downloaded, so you can stop and resume at any time with Ctrl+C.

**⚠️ Important:** Do NOT log into Soulseek locally while this script is running.
After it finishes and says "✓ Session is clean!", you can safely log in.
Run `./verify_clean_session.sh` to double-check before logging in.

### Phase 2b — Verify clean session (optional but recommended)

```bash
./verify_clean_session.sh
```

After Phase 2 completes, this verifies that the Soulseek session has properly
disconnected. Run this before logging into Soulseek locally to avoid account bans.

Output should be:
```
✓ Container not running
✓ No soulseek processes running
✓ Session is clean!
✓ Safe to log into Soulseek locally now
```

### Phase 3 — Rescan & merge

```bash
python3 03_rescan_and_merge.py
```

Triggers a Navidrome library scan, polls until it finishes, then
re-searches for the newly downloaded tracks. Updates `found_tracks.json`.

> **Note:** Navidrome must have `incoming/` in its watched music
> folder. Since it's inside `/opt/4TBExt/Media`, it should be picked
> up automatically.

### Phase 4 — Create the playlist

```bash
python3 04_create_playlist.py
```

Creates **"The Rock 2000 (2025)"** in Navidrome. Re-running updates the
playlist rather than creating a duplicate.

## Ban prevention

This pipeline is designed to be Soulseek-friendly and avoid account bans. Key safety features:

- **Search throttling**: Limited to 1 search per 20-minute window with 3-5 second random delays
- **Clean disconnects**: Container shuts down automatically after download, preventing duplicate sessions
- **Connection cleanup**: Explicit 30-second grace period to ensure Soulseek sees the disconnect
- **Session verification**: `verify_clean_session.sh` confirms the session is clean before you log in

### Avoiding ban during download

1. Do NOT log into Soulseek locally while `02_download_missing.sh` is running
2. Let the script complete to completion — it will auto-cleanup
3. Wait for the message: "✓ Session is clean!"
4. Optionally run `./verify_clean_session.sh` before logging in

### If banned

Wait 30+ days for Soulseek to unban the account. For details on the security setup and additional precautions, see `BAN_PREVENTION_REVIEW.md` and `CHANGES_SUMMARY.md`.

### Fuzzy matching misses obvious tracks
File tags may be messy. Run `MusicBrainz Picard` over your library to
retag, then re-run Phase 1. You can also lower `MATCH_THRESHOLD` to `0.70`
in the scripts.

### Fuzzy matching gives false positives
Raise `MATCH_THRESHOLD` to `0.85`.

### Soulseek finds nothing / very slow
- Check `config/not_found.txt` after the run
- Some obscure tracks genuinely aren't on Soulseek
- **CSV cleanup**: Phase 2 automatically cleans up search phrases (removes remaster
  suffixes, normalizes special characters like ö/ü). This significantly improves
  hit rate. Check the cleanup log output at the start of Phase 2.
- Try adjusting search timeout in `sldl.conf`: `search-timeout = 10000`
- Make sure Nicotine+ isn't logged in simultaneously with the same account
  (two logins with the same credentials causes connection issues)

### Tracks downloaded but not appearing in Navidrome
Phase 3 triggers a rescan automatically. If it still doesn't pick them up:
1. Check Navidrome's music folder path includes `/opt/4TBExt/Media/Music`
2. Check file permissions (`ls -la /opt/4TBExt/Media/incoming/`)
3. Manually trigger a scan: Navidrome → Settings → Library → Scan now

### Docker permission errors on downloaded files
```bash
# Check who owns the music folder
stat -c '%u:%g' /opt/4TBExt/Media/Music
# Set matching PUID/PGID in docker-compose.yml, then:
docker compose down && docker compose up -d
```

### Tracks not found on Soulseek (config/not_found.txt)
Options for manual sourcing:
- **yt-dlp**: `yt-dlp -x --audio-format flac "ytsearch1:Artist - Title"`
- **Bandcamp**: good for NZ/indie artists (Shihad, Blindspott, etc.)
- **CD ripping**: if you own the album (Whipper on Linux)
